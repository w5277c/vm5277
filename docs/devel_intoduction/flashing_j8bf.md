# Прошивка микроконтроллера утилитой j8bf

Здесь описана работа с утилитой j8bf — основным инструментом тулкита VM5277 для обновления прошивки микроконтроллеров через программный UART-интерфейс (одно или двухпроводной режим).

## Автоматические варианты прошивки на базе j8bf

### Прошивка через Maven
Изучите статью [Создание первого проекта](first_project.md) — пункт "Автоматическое создание через Maven-плагин" для ознакомления с процессом создания и сборки проекта.  
После сборки проекта достаточно выполнить команду:
```bash
mvn j8b:run
```
В результате будет запущена утилита j8bf и выполнена прошивка устройства.

## Основной способ прошивки консольной утилитой j8bf

### Формат команды:
```bash
j8bf <платформа>:<микроконтроллер> <частота_МГц> <файл_прошивки.hex> [опции]
```

### Основные опции:
* **-S, --serial <устройство>** — указать конкретный последовательный порт (например, /dev/ttyUSB0 или COM0).
* **-s, --smart** — включить умный режим прошивки (перезаписываются только изменённые страницы hex файла).
* **-e, --encrypted** — указать, что прошивка зашифрована.
* **-C, --clear-cache** — очистить кэш прошивки для данного устройства (используется для smart режима).
* **-E, --erase** — очистить память МК (не затрагивает бутлоадер).
* **-F, --flash** — выполнить прошивку.
* **-V, --verify** — проверить прошивку.
* **-R, --reboot** — перезагрузить устройство по завершению.
* **-I, --interactive <mode>** — интерактивный режим (auto, none, out, full).
* **-f, --fwversion <num>** — установить версию прошивки (значение 0-255).
* **-w, --wait** — ожидание устройства (10 сек) полезно при необходимости ручной перезагрузки МК для выхода в бутлоадер.
* **-r, --retries <число>** — количество попыток при ошибках (по умолчанию 3).
* **-q, --quiet** — тихий режим (минимальный вывод информации).
* **-x, --tsize** — размер терминала в символах (width/height)
* **-v, --version** — показать версию утилиты.
* **-h, --help** — вывод подсказки по использованию утилиты.


### Индикаторы прогресса:
* **e/w** — страница стёрта/записана с первой попытки.
* **E/W** — страница стёрта/записана с повтором (первые попытки были с ошибкой).
* **i/I** — страница идентична (с первой попытки / после повтора).
* **s** — страница пропущена в умном режиме (кэш совпадает).
* **-** — страница пропущена (нет данных в HEX-файле для этого адреса).

### Интерактивные режимы:
* **auto** — программатор выбирает режим на базе активных фич собранного проекта
* **none** — интерактивный режим отключен - после выполненных команд работа флешера завершается
* **out** — выполняется только транслирование вывода с МК в консоль флешера
* **full** — полнофункциональный режим, выполняется двухстороннее транслирование ввода-вывода, а также поддержка VT100 стандарта (вероятно потребует отдельного окна с терминалом)

### Определение устройства
Кроме задач обновления прошивки эта утилита также может выполнять поиск подключённых плат с выводом базовой информации о них.
Пример использования:
```bash
j8bf detect 16
Flasher v.0.4.0: firmware flasher for vm5277 Embedded Toolkit
Toolkit path: /home/kostas/vm5277

Serial port: /dev/ttyUSB0
Connection mode:2 wire mode
Device info:BLDR NORMAL v.03: AVR, sig:001e950f, uid:3427bffa7c45f871, stdio port:PD0/PD1
avr:ATmega328P PD0/PD1
```

### Пример использования:
```bash
j8bf avr:atmega328p 16.0 Main_cseg.hex -s -S /dev/ttyUSB0 -F -V -R 
```
Эта команда:
* Подключается к ATmega328p, работающему на 16 МГц.
* Записывает файл Main_cseg.hex.
* Использует умный режим прошивки.
* Использует последовательный порт /dev/ttyUSB0.
* Проверяет записанное содержимое.
* Перезагружает микроконтроллер после успешной прошивки.

### Рекомендация использования для первой прошивки:
```bash
j8bf avr:atmega328p 16.0 Main_cseg.hex -s -F -V -R 
```
Утилита выполнит поиск чипа atmega328p платформы avr подключённого через COM порт (в том числе и USB-UART преобразователи) и при нахождении выполнит прошивку и проверку прошивки Main_cseg.hex в текущем каталоге, а затем перезапустит МК для выполнения новой прошивки.

## Примечания:
* Для работы j8bf требуется установленный бутлоадер VM5277 на целевом устройстве (см. полезные главы в начале главы).
* Умный режим (-s) использует кэширование прошивок в директории var/mcu_caches тулкита.
* При использовании шифрования (-e) умный режим недоступен, запись выполняется для всей Flash исключая бутлоадер.
* Опции -E, -F, -V, -R утилита выполняет в строгой последовательности: очистка (E) → прошивка (F) → верификация (V) → перезагрузка (R)

Если вы не указали порт (-S), утилита выполнит автоматический поиск подключённого устройства с бутлоадером VM5277.
